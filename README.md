# E-Portfolio
## นายอธิป นุ่มนวลศรี

ยินดีต้อนรับเข้าสู่เว็บไซต์แฟ้มสะสมผลงาน (E-Portfolio) ของนายอธิป นุ่มนวลศรี

เว็บไซต์นี้จัดทำขึ้นเพื่อรวบรวมประวัติส่วนตัว ทักษะ ความสามารถ ผลงาน และกิจกรรมต่าง ๆ เพื่อแสดงถึงความรู้และประสบการณ์ด้านเทคโนโลยีและคอมพิวเตอร์

---

## ✨ Features

- หน้าแรก (Home)
- แนะนำตัว (About Me)
- ผลงาน (Portfolio)
- กิจกรรม (Activities)
- ช่องทางการติดต่อ (Contact)
- Responsive Design รองรับคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- Dynamic Animations และ Scroll Effects
- Lightbox Gallery สำหรับแสดงภาพ
- Smooth Scrolling
- Active Navigation
- Font Awesome Icons
- Google Fonts รองรับภาษาไทย

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts (Kanit & Prompt)
- Font Awesome 6

## 🎨 Design

- Crimson Red
- Golden Yellow
- Dark Brown

ออกแบบให้มีความสวยงาม ทันสมัย และใช้งานง่าย

## 📂 Project Structure

```text
E-Portfolio/
├── index.html
└── README.md
```

เว็บไซต์เวอร์ชันไฟล์เดียวฝังรูปโปรไฟล์ไว้ภายใน HTML แล้ว จึงไม่จำเป็นต้องแยกไฟล์รูปภาพเพิ่มเติม

## 🚀 How to Use

1. ดาวน์โหลดไฟล์เว็บไซต์
2. เปิดไฟล์ `index.html`
3. ใช้งานผ่าน Google Chrome หรือเว็บเบราว์เซอร์อื่น ๆ

## 🌐 Deployment

สามารถนำเว็บไซต์ไปเผยแพร่ผ่าน GitHub Pages ได้

1. สร้าง Repository บน GitHub
2. อัปโหลดไฟล์เว็บไซต์
3. เข้าไปที่ Settings
4. เลือก Pages
5. เลือก Branch ที่ต้องการ
6. กด Save เพื่อเผยแพร่เว็บไซต์
